# Data Analysis Assignment

## Project Overview
This project demonstrates fundamental data analysis skills using Microsoft Excel, SQL, and Python.

## Milestone 2: Excel Sales Analysis
- Sales data cleaning and preparation
- Formula-based calculations
- Region-wise, category-wise, and monthly sales summaries
- Sales charts and visualizations

## Milestone 3: Python Exploratory Data Analysis (EDA)
- Data analysis using Pandas and NumPy
- Handling missing values
- Exploratory analysis and summary statistics
- Data visualization using Matplotlib and Seaborn

## Milestone 4: SQL Analysis
- Database and table creation using MySQL
- Sales data insertion and retrieval
- Region-wise and category-wise revenue analysis
- Total revenue, total cost, and profit calculations

## Tools Used
- Microsoft Excel
- MySQL / MySQL Workbench
- Python
- Pandas, NumPy, Matplotlib, Seaborn
- GitHub

## Repository Contents
- Excel sales analysis workbook
- SQL scripts and query output workbook
- SQL execution screenshots
- Python EDA notebook
